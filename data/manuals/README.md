# Manual corpus

PDFs are not committed - Siemens copyright. Download them here.

| File | Siemens document |
|---|---|
| `s71200_system_manual.pdf` | S7-1200 Programmable Controller System Manual (ID 109764129) |
| `s71200_easy_book.pdf` | S7-1200 Easy Book |
| `sinamics_g120_function_manual.pdf` | SINAMICS G120 Function Manual |
| `sinamics_g120_faults.pdf` | SINAMICS G120 fault and alarm list |

Search Siemens Industry Online Support (https://support.industry.siemens.com)
for each title or document ID, download the English PDF, and save it here
with the filename above. Filenames appear in citations, so keep them readable.

Then build the index:

    python src/index.py
