# Manual corpus

PDFs are not committed — they are Siemens copyright. Download them here.

| File | Source |
|---|---|
| `s71200_easy_book.pdf` | Siemens Industry Online Support, S7-1200 Easy Book |
| `sinamics_g120_function_manual.pdf` | Siemens Industry Online Support, SINAMICS G120 Function Manual |
| `sinamics_g120_faults.pdf` | SINAMICS G120 fault and alarm list |

Search Siemens Industry Online Support (https://support.industry.siemens.com)
for each title, download the English PDF, and save it here with the
filename above. Filenames appear in citations, so keep them readable.

Then run:

    python src/index.py
